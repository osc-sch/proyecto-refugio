## Descripción
Sitio web informativo sobre un refugio de perros en situación de calle de la ciudad de Formosa.
## Distribución de tareas
- Alvarenga Sofía: index.html y página de castrar
- Caballero Alejandro: archivo README.md, página de nosotros, buscar y estilos del menú.
- Schneider Oscar: pagina contacto, pagina de adopción y footer.

¿Qué ventaja encontraron al trabajar con Git y GitHub?
-Nos dio muchas facilidades para poder trabajar de forma simultánea, nos permite tener un mejor control sobre el proyecto, corregir, agregar, modificar o eliminar archivos como imagenes, html, css.
¿Qué problema tuvieron al trabajar entre varias personas?
-Nos surgieron algunos problemas, como poder subir el trabajo de manera adecuada para que no hayan problema en la edicion final.
¿Por qué creen que usar ramas ayuda en un trabajo colaborativo?
-Creemos que si nos ayuda, porque cada uno puede concentrarse en trabajar en su propia parte del trabajo sin tener que preocuparse por arruinar el proyecto entero.
